# Reference atlas: decisions worth studying

Research checked 2026-10-22. This is a curated craft sample, not an industry census or evidence of production budget or conversion uplift. Dates below distinguish publication from launch. Studio descriptions support claims about their process; interpretation is marked as a lesson, not measured causality. Full audiovisual reviews were not performed for these entries.

Use one or two references to resolve the current creative question. Verify the actual film before borrowing exact timing. Do not install tools or reproduce another brand's assets merely because they appear here.

## Product explanation

### Linear for Agents

[Original launch page and film](https://linear.app/changelog/2025-05-20-linear-for-agents), dated May 20, 2025. Evidence: publisher text, selected browser frames around 0:10, 0:20 and 0:25, and limited muted opening playback. Samples show issue activity, agent responses and titles in a restrained dark interface.

**Lesson:** a familiar input and visible response can do the explanatory work; titles can punctuate instead of duplicating it. **Use for:** products whose actual interactions are legible and distinctive. **Limit:** dense UI still needs reframing for small players. The samples do not establish exact easing or musical timing.

### Bandwidth Synthi

[Banona case study](https://www.banona.co/work/bandwidth-synthi), labeled 2025. Evidence: maker's description, not full playback. The studio describes a move from interface context to a notification close-up when activation matters.

**Lesson:** direct attention at the decisive state change. **Use for:** a product with an understandable trigger and consequence. **Limit:** a push toward a generic dashboard detail does little unless the detail proves the point. Reconstruct the relationship from the current product.

### Atono and Josys

[Vidico Atono](https://vidico.com/case-studies/atono/) and [Josys](https://vidico.com/case-studies/josys/). Case-study dates in the publisher index: July 4, 2025 and January 21, 2026; these are not confirmed film premieres. Evidence: written case studies. Atono combines UI demonstration and graphic explanation; Josys organizes focused feature stories under a common motion system.

**Lesson:** reuse spatial rules and behavior while allowing each feature its own composition. **Use for:** a family of product cutdowns. **Limit:** identical title-and-card layouts can flatten different stories. Studio performance claims are not independent causal evidence.

## Concept and motion identity

### This is Figma, Config 2026

[Oddfellows case study](https://oddfellows.tv/work/figma), [publisher film](https://framerate.tv/watch/J3zWHMu3). The studio places it at Config 2026; the player displayed August 21, 2026 as its posting date. Evidence: case-study text and selected frames around 0:09 and 0:29, not full playback. The studio frames code and design as different languages developing into one creative language.

**Lesson:** let the visual system evolve with the argument. **Use for:** a launch with a meaningful conceptual change to express. **Limit:** a conference anthem has different duties from a short product demonstration. Borrow the development of an idea, not its colors or motifs.

### Comfy Brand Refresh

[BUCK case study](https://buck.co/work/comfy-brand-refresh), project date unconfirmed. Evidence: maker's description and a selected browser image. The documented system draws on nodes, modularity and user control, using connecting forms and spatial reveals.

**Lesson:** the product's organizing principle can become its motion behavior. **Use for:** modular or relationship-driven products. **Limit:** nodes are inappropriate shorthand for a product whose user value is unrelated to networks. A current footer is not a project date.

### Figma Config 2025 process

[Figma's process account](https://www.figma.com/blog/how-we-shaped-the-visual-identity-for-config-2025/), published July 3, 2025. Evidence: primary article and limited visual samples. The account describes concept exploration, expressive and functional type behaviors, deliberate 15fps motion and related sound motifs.

**Lesson:** cadence and material are authored choices; maximum smoothness is not the only quality target. **Use for:** a brand that benefits from tactile, graphic or handmade expression. **Limit:** stepped motion on small UI labels can reduce readability. Test the chosen cadence in the actual export.

### Notion AI Assistant

[BUCK case study](https://buck.co/work/notion-ai), date unconfirmed. Evidence: written process, not full animation viewing. The studio describes a character communicating interactive states, with authored performances carried into Rive.

**Lesson:** distinctive behavior can communicate state more clearly than generic AI decoration. **Use for:** products with meaningful thinking, error or completion states. **Limit:** a mascot is not required; the transferable idea is semantic behavior. This is a product motion system, not a promotional-film timing template.

### Nothing Playground

[BUCK case study](https://buck.co/work/nothing-playground), [official launch context](https://nothing.community/d/43142/1), September 2025. Evidence: written case study. It describes vectors, organic material and imagery processed through the brand's grid, pixel and type system, with extensive exploratory tests.

**Lesson:** controlled contrast can add richness without losing identity. **Use for:** a brand that genuinely accommodates graphic and tactile material. **Limit:** adding texture or mixed media without a shared visual rule creates clutter.

## Older craft reference

[Ordinary Folk: Webflow, A New Era of No-Code](https://www.ordinaryfolk.co/project/webflow-a-new-era-of-no-code), premiered November 2021, [studio upload](https://www.youtube.com/watch?v=eEW2gr7K7kc) January 10, 2022. Evidence: maker text and published frames, no full playback. Its established visual language expands to introduce product capabilities.

**Lesson:** new expression can develop an existing brand rather than reset it. **Limit:** its longer conference format is not evidence for the pacing of a short social film. See also [Ordinary Folk's process](https://www.ordinaryfolk.co/process) for the relationship between message, design, animation and sound.

## Tools and skills: borrow the method

| Source | Transferable idea | Boundary |
|---|---|---|
| [Official Remotion skills](https://github.com/remotion-dev/skills) | Frame-based implementation and current API guidance | Check against installed versions; APIs do not select a concept |
| [Impeccable](https://github.com/pbakaus/impeccable) | Explicit direction and critique against it | Frontend rules and aesthetic bans do not automatically apply to film |
| [GSAP Flip](https://gsap.com/docs/v3/Plugins/Flip/) and [GSAP skills](https://github.com/greensock/gsap-skills) | Preserve object identity across layouts | Borrow choreography before considering another runtime |
| [Motion Canvas time events](https://motioncanvas.io/docs/time-events/) | Name events by editorial meaning | Useful method, not a reason to change engines |
| [Rive interpolation](https://rive.app/docs/editor/animate-mode/interpolation-easing) | Author motion character through curves | Overshoot is one behavior, not a quality score |

[Linear's Output isn't design](https://linear.app/now/output-isn-t-design), April 17, 2026, is a useful process argument for resolving the design problem before multiplying polished variants. It is a perspective, not a controlled study of agent output.

## Adding a reference

Record source, access date, publication confidence, viewing method, observed interval, communication problem, mechanism, takeaway and failure condition. Separate observation from interpretation. Store client-specific analyses in that client's project. Keep this atlas reusable and free of private assets, claims and production history.
